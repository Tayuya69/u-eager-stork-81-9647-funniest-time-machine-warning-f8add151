## The entry

> CAUTION: Do not step on butterflies. One of them has already sued, and the hearing is in 1852.

## How it works

`main.ts` deterministically writes the entry line above to `/output/entry.txt` (94 characters, one line, no trailing newline), then re-reads the file and verifies it matches exactly. No randomness, no network, no input.

Run it with Node 22 or later:

```sh
node main.ts
```
